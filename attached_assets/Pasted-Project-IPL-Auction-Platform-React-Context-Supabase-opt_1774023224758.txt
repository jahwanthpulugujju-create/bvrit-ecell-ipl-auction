1. ROLE-BASED ACCESS CONTROL (CRITICAL)
--------------------------------------------------

Define 3 roles:
- admin
- team_user
- public_viewer

Create a global auth state:
auth = {
  role: "admin" | "team_user" | "public",
  teamSlug?: string
}

Rules:
- Admin → full access
- Team → only own team
- Public → only display page

--------------------------------------------------
2. TEAM AUTHENTICATION SYSTEM
--------------------------------------------------

2.1 Team Login Flow:
- Route: /team-login
- Inputs:
  - team name (slug)
  - password

2.2 On success:
- Store in sessionStorage:
  {
    role: "team_user",
    teamSlug: "<team_slug>"
  }

2.3 Protect routes:
- /team/:slug
  IF not logged in → redirect to /team-login
  IF slug !== session.teamSlug → show "Access Denied"

2.4 Remove all open access to team dashboards
